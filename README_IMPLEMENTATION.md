## 🔧 Cara Menggunakan

### Akses Halaman:
1. Copy file **proses-jasa.html** ke root folder website
2. File CSS & JS sudah di folder yang benar
3. Akses di browser: `https://yoursite.com/proses-jasa.html`

### Edit Konten:
1. **Buka** proses-jasa.html dengan text editor
2. **Cari** teks yang ingin diubah
3. **Edit** sesuai kebutuhan
4. **Save** dan refresh browser

### Ganti Gambar:
1. Siapkan 3 gambar (pengeboran, besi, beton)
2. Simpan di folder `imgs/`
3. Update path di HTML:
   ```html
   src="imgs/nama-gambar-baru.jpg"
   ```

### Dokumentasi Lengkap:
- Lihat `DOKUMENTASI_PROSES_JASA.md` untuk detail lengkap
- Lihat `QUICK_REFERENCE.md` untuk update cepat
